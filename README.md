# EL TATÚ ENAMORADO — Pictocuento accesible
Aplicación web estática (HTML + CSS + JS, sin dependencias ni conexión externa).
Publicar: subir la carpeta a GitHub Pages (Settings → Pages → rama main / raíz) o arrastrarla a Netlify Drop.
Probar local: `python3 -m http.server` y abrir http://localhost:8000
